Tree navigation via context + tree

NAC.context(plugin) returns the breadcrumb of the currently focused node walking up to the plugin root. NAC.tree(plugin, rootId?) enumerates immediate addressable children. data-nac-opens declares parent-to-child relationships; data-nac-leaf marks terminals. Labels are resolved via narrate.
