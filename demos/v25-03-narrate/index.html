Asistive labels via narrate

Voice runners, screen readers, audit logs and any assistive flow need ONE canonical way to ask "what is this thing called?". The runtime returns the label following a strict priority order: aria-label > visible text > data-nac-label > nac_id fallback. Nested addressable children are skipped so the spoken output stays scoped to the element you asked about.

plugin: editor toolbar
