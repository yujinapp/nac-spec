NAC3 v2.6 -- RFC V26-01 demo

The plugin contract against a library we do not control

The map in the centre is a real Leaflet 1.9.4, loaded from unpkg with a pinned hash. The plugin that makes it operable lives in its own file, leaflet-nac-plugin.js, and uses nothing but the published runtime surface -- registerApiHandle and registerPlugin. That is the whole point: a canvas surface can live in another repository, under another licence, attached to this Apache core without a byte of it changing.

The six v2.6 hooks

E-1 / E-2 -- discovery

An agent that never read the plugin file asks the runtime what is here, and gets the verbs, their labels and the shape of their arguments.

E-4 -- sdk-call, positional, off-window
E-3 -- emitter-listen

Leaflet's own moveend, declared in the manifest. Drag the map and watch the log.

E-5 -- the observer that observed nothing

A city row exists only while the city is in view. Without root the subscription is refused instead of coming back as a handle that never fires.

E-6 -- the plugin's own error code
