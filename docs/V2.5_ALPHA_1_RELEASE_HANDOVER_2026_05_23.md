## Migration done in this release

Before today, NAC3 lived in two places (rpaforce-crm monorepo +
yujinapp/nac-spec public repo) with diverging content. The May 2026
session discovered the divergence the hard way: 6 commits to the
wrong repo + 1 inadvertent npm publish.

**Resolution:**

1. Two parallel v2.4 lines unified into v2.5.0-alpha.1.
2. `yujinapp/nac-spec` becomes the SOLE source of truth for NAC3.
3. `rpaforce-crm/packages/nac/` + `rpaforce-crm/yujin.app/nac-spec/`
   deleted in `0ff3afa`.
4. Local working dir for NAC3 is now `c:/yujin-nac-spec/`. The
   rpaforce-crm monorepo holds CRM code only.

**Norms documented in PROJECT.md (NEW at repo root):**

- Repo topology section -- prevents the "wrong repo" mistake.
- RFC process with 5 states: Proposed / In implementation /
  Implemented / Alpha / Production.
- Doc-update invariant: every RFC transition touches index + spec
  + changelog + USER_MANUAL + TECHNICAL_DESIGN + demos list +
  benchmark numbers + Sumi Discord KB.
- Programming + architecture norms: 100% test PASS, TDD,
  agnostic-by-default, zero internal fallback, zero silent damage,
  industrial quality.
- Code style + multi-language discipline + provenance discipline.
- 10-step cycle of work from idea to production.
